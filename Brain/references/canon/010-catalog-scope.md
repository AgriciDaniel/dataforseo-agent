# Catalog scope

#confidence/evidence-based

Paraphrase: the OpenAPI spec and docs index list 583 endpoints across 11 data APIs plus Appendix (565 in the spec, 18 from the docs only). In the catalog 576 are active; 7 are deprecated, removed or unavailable (live test 2026-11-06). Databases is a file product with no endpoints, Content Generation is discontinued and Google Events is deprecated.
