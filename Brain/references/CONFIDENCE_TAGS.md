# Confidence tags

Every wiki note carries `confidence:` in frontmatter; canon entries carry a `#confidence/...` tag.

| Level | Meaning in this brain |
|---|---|
| evidence-based | Stated by an official DataForSEO source (docs, OpenAPI spec, pricing page, official repo) or checked against the endpoint catalog, with a date. |
| practitioner | Recommended practice built on official facts but not itself stated by DataForSEO (defaults, workflow order, tradeoffs), or third-party data such as competitor index sizes. |
| contested | Sources disagree or a value changed recently; the note says which source wins. |
| folklore | Widely repeated but unverified. Never used as a basis for spend or routing. |
