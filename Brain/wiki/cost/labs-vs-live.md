# Labs vs live data

- If the answer does not need the last 24 to 48 hours, use pre-indexed **Labs** (keyword ideas, difficulty, intent, ranked keywords, competitors, traffic estimates) instead of live SERP or Google Ads calls. One Labs call returns up to 1000 items.
- Use **live SERP** for current rankings, SERP features and AI Overview state; use **Keywords Data** for Google Ads ground-truth volume and bids on a small, final set.
- **Databases** (bulk file dumps) only for whole-corpus offline analysis; quoted per dataset, not per call.
- Labs and clickstream numbers are estimates; say so when reporting them.
