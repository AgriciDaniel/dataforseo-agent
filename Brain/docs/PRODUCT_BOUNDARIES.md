# Product boundaries

Maturity: see the latest Brainstein run in `_review/` (status and score are recorded there, not claimed here).

## It does
- Route a DataForSEO job to the right module and endpoint.
- Explain execution modes, limits, errors and billing, and estimate cost from the endpoint catalog.
- Provide workflow skills with endpoints in order and cost formulas.
- Cite dated official sources for DataForSEO facts.

## It does not
- Cover other SEO tools beyond comparison context.
- Hold endpoint parameters or prices as truth (the catalog does).
- Call the API itself, store credentials, or approve spending. Spending needs the user's approval each time.
- Guarantee estimates: Labs, clickstream and spam scores are model estimates.
